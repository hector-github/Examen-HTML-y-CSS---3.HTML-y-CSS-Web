## 📌 Descripción

Proyecto web desarrollado como **entrega de examen**.  
Se trata de una página completa con diseño moderno, animaciones, formulario funcional y estructura semántica.

El sitio incluye:

- Cabecera con gradiente animado
- Menú de navegación
- Secciones de contenido
- Galería de imágenes
- Formulario de presupuesto completo
- Sección de contacto
- Footer

---

## 🛠️ Tecnologías utilizadas

- **HTML5** → Estructura semántica
- **CSS3** → Estilos, animaciones, diseño visual
- Tipografías: `Audiowide`, `Lato` y `Playfair Display`
